CLAPPING CAT — Forge 1.20.1 (47.2.0), Java 17
=============================================

Что в моде
- Моб "Clapping Cat": 1000 HP, 100 урона за удар, броня 20, скорость 0.42, радиус агро 48
- Настоящая анимация хлопков: руки вперёд, ладони сходятся/расходятся
  (лениво в покое, бешено когда гонится/бьёт)
- Звук тяжёлого хлопка при каждом попадании; кошачьи звуки (ambient/hurt/death)
- Новая модель (лапы стоят на земле) и текстура (чёрный кот, золотые глаза, белые лапки)
- Яйцо призыва в Creative (вкладка Spawn Eggs) с корректной иконкой
- Не деспавнится (persistent)

Как собрать
1. Установи JDK 17 (если нет — Gradle сам скачает через toolchain, нужен интернет).
2. Установи Gradle 8.x (или добавь gradle wrapper).
3. В папке проекта:  gradle build
   (первый раз долго — качается Minecraft/Forge)
4. Мод: build/libs/clappingcat-1.0.0.jar  -> положить в .minecraft/mods (Forge 1.20.1).

Заметки
- В Peaceful моб исчезает (как любой Monster) — для роликов ставь Easy/Normal/Hard.
- Вызвать командой: /summon clappingcat:clapping_cat
- Проект не компилировался в среде, где он правился (нет доступа к Forge) —
  если gradle build выдаст ошибку, скинь текст ошибки.
